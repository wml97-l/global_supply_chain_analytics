# Global Supply Chain Analytics

## Overview

This project analyzes global shipment operations to identify
transportation inefficiencies, evaluate supply chain risk factors,
and predict shipment disruptions using machine learning.

## Objectives

- Analyze shipment performance
- Evaluate transport mode efficiency
- Assess geopolitical and fuel price risks
- Predict shipment disruptions
- Develop interactive Power BI dashboards

## Technologies

- Python
- Power BI
- Pandas
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Dataset

Global shipping dataset containing:

- Shipment records
- Transport modes
- Lead times
- Reliability scores
- Fuel price index
- Geopolitical risk scores

## Machine Learning Results

Model Performance:

- Accuracy: 72%
- Macro F1 Score: 0.72
- ROC-AUC: 0.79

SMOTE was applied to address class imbalance and improve minority class detection.
